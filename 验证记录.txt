修复内容
1. 前台、后台共用 click_point（网页控件局部坐标）。
2. 后台取点直接保存坐标，不再查询网页元素或保存 DOM 指纹。
3. 后台执行向 Chromium render widget 发送移动、左键按下、左键松开。
4. 后台不调用系统 SetCursorPos/mouse_event，不激活或提升软件窗口。
5. 越界、输入控件未就绪或异常时停止自动操作；不回退为前台点击。

验证环境限制
- 工具运行于隔离测试桌面，GetForegroundWindow 返回空值。因此“活动前台窗口始终属于另一软件”的断言跳过，不能把空句柄不变当作完整的焦点保持验证。
- 该运行环境需仅在测试进程设置 QTWEBENGINE_DISABLE_SANDBOX=1 才能加载本地测试页；未将此设置加入软件或打包配置。默认沙箱开启的本机/打包环境仍需运行随包测试确认。
- 未运行 OCR 模型、完整主窗口的所有功能、用户实际网站、最小化/隐藏窗口测试或 EXE 构建。
- 本包是完整源码修复包，不包含已编译 EXE；原 GitHub Actions 打包入口保留并已更新为 Qt WebEngine 测试。
