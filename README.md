# 网页刷新数字监控 V24.2

本版本基于 V24.1 稳定版修复，重点增加后台点击与网页元素拾取。

## 定时操作
- 刷新网页
- 后台点击拾取点位：使用网页 DOM 的 elementFromPoint + click，不移动 Windows 系统鼠标
- 后台点击网页元素：通过 CSS Selector / XPath 定位并执行 DOM click，不移动系统鼠标

## 网页元素拾取
点击“🎯 拾取网页元素”后，鼠标移动到网页元素上会显示青色高亮边框；点击后确定元素，并保存 CSS Selector、XPath、标签和文本。按 ESC 可取消。

## 注意
后台点击适用于网页自身 DOM 事件。若某网页只接受真实操作系统鼠标事件，DOM click 可能不会触发该网页的全部行为。
