# 网页刷新数字监控 V12.0

## 本版本主要修改

### 1. 识别框改为软件内部显示
原来的识别框是全屏置顶 Overlay，会覆盖其它软件。
V12.0 已取消全屏置顶识别窗口，识别框只显示在软件右侧的“软件内识别画面”中。

### 2. OCR 仍然后台抓取真实屏幕
OCR 不依赖识别框窗口存在。
每次检测时先抓取一次真实屏幕，再从完整截图中裁剪所有 ROI 区域进行 OCR。
因此可以把监控软件最小化、切换到网页/其它程序，OCR 定时检测仍然继续。

### 3. 框选调整改为软件内部操作
点击“📐 软件内调整识别框”，在软件内部的识别画面上：
- 拖动已有框移动
- 拖动四角调整大小
- 空白区域拖动新增框
- 点击“完成”保存新的坐标

保存的 ROI 仍然使用真实屏幕坐标，因此后台 OCR 使用的监控位置不变。

### 4. 报警显示
报警区域在软件内部识别画面中显示红框，并保留“消除报警”按钮，不再覆盖其它软件。
