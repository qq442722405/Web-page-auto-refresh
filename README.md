# 网页刷新数字监控 V24.0

## 本版修改
- 删除设置界面中的浏览器内核介绍。
- 将“刷新间隔”改为“操作间隔”。
- 到达操作间隔后，可选择：
  - 刷新网页
  - 点击拾取的网页点位
- 新增“📍 拾取点位”，点击后在网页中直接选择坐标。
- 点击点位按屏幕坐标保存，程序重启后仍可使用。
- 保留原有 OCR、识别框、报警、截图、账号、日志、Chromium WebEngine、高性能 GPU 与磁盘缓存。
- 自动操作关闭时不会执行周期操作。
- 手动刷新仍可使用原加载按钮。

## 构建
GitHub Actions 使用 workflow_dispatch 手动触发，PyInstaller 使用 onedir。


## V24.1 修复版说明
- 修复启动入口对 `MainWindow` 的直接引用，启动前显式检查主窗口类是否完整加载。
- 保留 V24.1 原有“操作间隔 / 刷新网页 / 点击拾取点位 / OCR / 报警”等功能。
- 本工程已进行 Python 语法编译检查。
