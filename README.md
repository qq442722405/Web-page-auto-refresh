# 网页刷新数字监控 V24.3 · 网页后台点击版

完整源码工程，保留刷新、前台点击、OCR、账号填充、识别框与悬浮控制栏；新增内嵌网页 DOM 后台点击。本次不附预构建 EXE。

## 三种操作模式

- **刷新网页**：保留加载中保护、刷新节流与定时调度。
- **前台点击（移动鼠标）**：旧配置 `operation_action: click` 含义不变。保存网页控件局部坐标，执行时转换为屏幕位置并移动真实鼠标。使用时必须保证目标窗口/网页在前台且无遮挡，避免误点其他窗口。
- **后台点击（网页元素）**：新增 `background_click`。通过内嵌页面 `runJavaScript` 找到元素，每次只调用一次 `element.click()`；不移动系统鼠标、不主动激活窗口、失败不回退到前台点击。界面仅报告“已触发点击”，不能据此判断网页业务完成。

## 使用

1. 加载需要操作的网页，选择后台点击模式。
2. 点“拾取网页元素”，设置浮层自动收起；在网页按钮/链接上选一点，拾取本身不会点击网页。Esc 取消。
3. 查看目标摘要，点“测试一次当前操作”；确认网页上的业务结果，再开启自动操作。
4. 目标成功拾取后自动保存；前台坐标和后台元素分别保存。旧坐标不会自动升级为后台元素。重新拾取会先清除旧后台目标，失败时不会偷偷继续使用旧目标。
5. 设置为右侧覆盖式滚动面板，打开/关闭不重新分配网页宽度；小窗口可在面板内纵向滚动。

测试按钮会真实执行当前操作，前台模式会移动鼠标，刷新模式会刷新网页，并非模拟预览。

## 定位与安全边界

- 唯一 CSS 选择器优先，必要时 XPath；同时核对标签、ID、文字、链接等指纹。目标改名、丢失、禁用或结构失配时要求重新拾取，宁可失败也不猜测目标。
- 支持同源 iframe 路径；不支持跨域/隔离源 iframe、Shadow DOM、canvas 精细坐标、带 CSS transform/zoom 的 iframe 拾取及捏合视口缩放。
- 普通浏览器缩放按 Qt 局部逻辑像素 / WebEngine zoomFactor 转 CSS 视口坐标；不再次乘设备像素比。滚动时使用视口命中测试。
- DOM 事件不是可信硬件事件。仅监听 pointerdown/mousedown、要求 `isTrusted`、用户手势、弹窗/支付授权的网站可能不响应；不会绕过这些限制。
- 执行中禁止重复操作；5 秒超时、停止、切模式、导航会使旧回调失效。超时会关闭自动操作，避免未知结果后自动重试。已发送给浏览器的请求无法撤销，停止/导航不保证撤回已产生的点击；脚本执行前亦检查过期时间。
- 导航暂停倒计时，加载完成后在自动操作仍勾选时重新开始完整倒计时；切模式需要重新开启自动操作。
- 后台 DOM 点击不等于后台 OCR：OCR 仍使用桌面截图，遮挡、失焦、最小化可能影响识别。最小化页面也可能被 Chromium 节流，后台点击不是实时执行保证。

## 运行与打包

建议 Windows + Python 3.11，在本目录创建虚拟环境后安装 `requirements.txt`，运行 `python main.py`。OCR/WebEngine 依赖较大，请在确实需要运行完整软件的环境安装。

GitHub 仓库根目录应为本 `v24` 目录（main.py、requirements.txt、.github 同级）。在 Actions 手动运行 Windows EXE 工作流：语法检查、轻量测试、已安装 Edge 的 DOM 测试、OCR 模型初始化，然后 PyInstaller 目录版构建。下载完整产物目录，不要单独拷贝 exe。缺少可选日志文件不再导致构建失败。

## 测试

不安装 GUI/OCR 依赖也能运行：

```powershell
python -m unittest discover -s tests -v
python -m compileall -q main.py background_click.py tests
```

可选真实 Edge DOM 集成测试（仅临时安装测试库，不下载浏览器）：

```powershell
uv run --no-project --with playwright python tests/test_browser.py
```

本地人工测试页：在 `tests` 目录执行 `python -m http.server 8765`，软件加载 `http://127.0.0.1:8765/fixture.html`。按钮计数保持在独立区域，便于判断每次是否仅触发一次；包含嵌套文字、链接、禁用项、canvas、同源和隔离源 iframe、长页滚动目标。
