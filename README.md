# 网页刷新数字监控 V24.0

## 本版本
- Chromium / Qt WebEngine 网页显示
- 页面设置：网页地址、缩放、操作间隔
- 操作间隔到达后可选择：
  - 刷新页面
  - 点击拾取的网页点位
- 点击点位可在网页中直接拾取，点位坐标保存到配置
- 操作启用、操作间隔、操作类型、点击点位等均可保存
- ddddocr + OpenCV 数字 OCR
- OCR 区域框选、报警、截图、账号设置
- 网页加载期间不会被定时操作强制刷新打断
- GitHub Actions 使用 workflow_dispatch 手动打包
- PyInstaller 使用 onedir 目录模式

## 点位操作说明
1. 在“页面设置”中将“到时间后”选择为“点击拾取点位”。
2. 点击“拾取点位”。
3. 在网页上点击需要自动点击的位置。
4. 点击“保存基础配置”。
5. 开启“启用操作”。
6. 每次操作间隔到达后，程序会自动点击保存的网页点位。

点位是网页视口坐标，网页缩放比例建议在拾取点位前确定。
