# 网页刷新数字监控 V13.0

## 本版本更新

### 1. 识别框直接显示在网页区域
识别框现在是网页浏览区域内部的透明 Overlay，不再创建全屏置顶窗口，也不再单独显示“软件内识别画面”。

打开其它软件时，本程序不会在其它软件上显示识别框。OCR 仍然按照真实屏幕坐标后台抓取并报警。

### 2. 网页右上角控制
网页右上角增加：
- 👁️ 隐藏识别框
- 👁️ 显示识别框
- ⚙️ 调整识别框

隐藏时只隐藏绿色/红色识别框，右上角控制按钮仍然保留。

### 3. 框选
点击“⚙️ 调整识别框”，直接在当前网页上拖动/缩放/新增识别区域。保存后仍使用真实屏幕坐标进行 OCR，因此保持旧配置兼容。

### 4. GitHub Actions
在线打包已改为**仅手动触发**，向 main/master 推送代码不会自动打包。进入 GitHub Actions 后点击“Run workflow”即可开始打包。


## V16.0 修改
- 右上角控制栏独立为可拖拽的最上层浮动窗口。
- 控制栏包含：刷新倒计时、OCR识别倒计时、隐藏/显示识别框、设置。
- 删除右上角“调整识别框”按钮；识别框调整入口仍可从设置面板进入。
- “设置”点击后打开设置浮层并变为“收起”，再次点击关闭。
- 控制栏按钮不再受网页识别 Overlay 的透明鼠标事件影响，保证可以正常点击。
- GitHub Actions 继续仅支持 workflow_dispatch 手动打包。
- 不包含自动内存清理功能。
