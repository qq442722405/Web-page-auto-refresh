# 网页刷新数字监控 V21.0

## 内核
本程序使用 **PySide6 Qt WebEngine**，其网页渲染内核为 Chromium 系列内核。不是调用系统 IE，也不依赖用户电脑安装 Chrome。

## 网页精简模式
设置菜单中增加可选的网页精简项目，可以逐项开启：

- 关闭图片加载：减少图片网络请求、流量和内存占用。
- 关闭网页字体加载：减少字体资源；可能改变页面字体样式。
- 关闭音频/视频资源：减少媒体资源加载。
- 关闭插件：默认开启，减少不必要插件负担。
- 关闭网页动画/CSS过渡：减少动画带来的 CPU/GPU 工作。
- 拦截常见统计/广告跟踪请求：只按常见跟踪域名特征拦截，不关闭核心 JavaScript。

JavaScript **不会被精简模式整体关闭**，避免破坏监控网页的数据更新、登录和交互功能。

修改精简选项后程序会在网页不处于加载状态时重新加载一次页面，使新设置生效。

## 刷新优化
自动刷新会检查网页是否仍在加载：

- 正在加载时跳过刷新；
- 页面加载完成后重新进入刷新周期；
- 避免“页面还没打开就又到时间刷新”的循环。

## 打包
GitHub Actions 使用 **workflow_dispatch 手动触发**，采用 PyInstaller `--onedir` 分目录模式。

最终产物：

`dist/网页刷新数字监控/网页刷新数字监控.exe`

整个 `网页刷新数字监控` 文件夹需要一起使用，不能只拿 EXE 单独运行。

## ddddocr
打包前会实际初始化 ddddocr 模型；PyInstaller 会收集 ddddocr 与 ONNX Runtime 的运行文件和模型。

## 日志
程序目录自动记录 `日志.TXT`，用于排查长期运行、网页加载、OCR 和 WebEngine 问题。
